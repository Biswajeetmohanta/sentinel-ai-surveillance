## 🎯 Field-by-Field Submission Cheat Sheet

### **1. Solution Presentation Link \***
- **Accepted Formats:** PDF, PPT, or PPTX
- **Prepared File in Project:**
  - `submission_package/Sentinel_AI_Solution_Presentation.pptx`
- **Action Steps:**
  1. Upload `submission_package/Sentinel_AI_Solution_Presentation.pptx` to your Google Drive (or save as PDF and upload).
  2. Right-click in Google Drive $\rightarrow$ **Share** $\rightarrow$ Set to **"Anyone with the link can view"**.
  3. Paste your Google Drive link into this form field.

---

### **2. High-Level Design / Architecture Document Link \***
- **Accepted Formats:** PDF, PNG, JPG, JPEG, or SVG
- **Prepared Files in Project:**
  - **Vector SVG Diagram:** `submission_package/01_High_Level_Architecture_Diagram.svg`
  - **Technical Specification (HLD):** `submission_package/01_High_Level_Design_Document.md`
- **Action Steps:**
  1. Upload `01_High_Level_Architecture_Diagram.svg` (and/or exported PDF) to your Google Drive.
  2. Set permission to **"Anyone with the link can view"**.
  3. Paste the shared link into this form field.

---

### **3. Workflow / Integration Diagram Link \***
- **Accepted Formats:** PDF, PNG, JPG, JPEG, or SVG
- **Prepared Files in Project:**
  - **Vector Workflow SVG:** `submission_package/02_Workflow_Integration_Diagram.svg`
  - **Integration Specification:** `submission_package/02_Workflow_Integration_Document.md`
- **Action Steps:**
  1. Upload `02_Workflow_Integration_Diagram.svg` (and/or exported PDF) to your Google Drive.
  2. Set permission to **"Anyone with the link can view"**.
  3. Paste the shared link into this form field.

---

### **4. Screenshots Folder Link**
- **Accepted Formats:** Screenshots folder or document link
- **Prepared Guide:**
  - `submission_package/04_Screenshots_Guide_and_Captures.md`
- **Action Steps:**
  1. Create a Google Drive folder named **`Sentinel_AI_Surveillance_Screenshots`**.
  2. Take screenshots of your running dashboard (`http://localhost:5173`) following the checklist in `04_Screenshots_Guide_and_Captures.md`.
  3. Upload the PNG files into the folder.
  4. Share the folder with **"Anyone with the link can view"** and paste the folder link into this form field.

---

### **5. Submit your solution (Video) and paste the Google Drive link \***
- **Accepted Format:** Google Drive link to MP4 video
- **Prepared Script & Guide:**
  - `submission_package/05_Video_Demonstration_Script_and_Guide.md`
- **Action Steps:**
  1. Record a 3–5 minute video demonstration following the script in `05_Video_Demonstration_Script_and_Guide.md`.
  2. Upload the `.mp4` video to Google Drive.
  3. Set permission to **"Anyone with the link can view"**.
  4. Paste the video Google Drive link into this form field.

---

### **6. Any other document or video submission**
- **Recommended Link:**
  - GitHub Repository Link or Complete Google Drive Package Folder containing the whole `submission_package/` directory.
